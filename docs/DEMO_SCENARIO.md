# Acme HealthTech guided demo

## Goal

Provide a predictable, one-click prospect demo that exercises the same persisted assessment, extraction-review, diagnostic, Entity/ID map, maturity/recommendation, report-version, and PDF-export boundaries used by uploaded assessments.

## Scenario

Acme HealthTech has a focused Patient identity problem across its Patient Portal, CRM, profile, and eligibility stack. Four architecture-metadata-only fixtures document multiple Patient identifiers, competing source-of-truth claims, duplicated matching/capability responsibilities, a long synchronous request chain, and a direct database dependency.

The fixtures contain no patient records, PHI, customer records, credentials, secrets, access tokens, or live production access.

## Walkthrough

1. Open `/sample` and choose **Launch guided sample**.
2. Review the assessment scope and the direct links to the sample surfaces.
3. Open **Extraction** to inspect the evidence-linked object inventory and the already completed review boundary.
4. Open **Findings** to inspect deterministic evidence-backed findings.
5. Open **Map** to show Patient, identifiers, systems, integrations, and accepted-finding overlays.
6. Open **Maturity** to show the focused risk-adjusted signal and prioritized recommendations.
7. Open **Report** to show the accepted-findings-only executive report and immutable saved version.
8. Use formal PDF/JSON export only from the persisted report snapshot.

## Demo behavior

The initializer is idempotent for the fixed sample assessment ID. It seeds server persistence, not browser-only mock state. If a different active assessment already occupies the single-assessment demo workspace, initialization fails with a clear conflict rather than deleting or mutating that assessment.

## Evidence rules

All sample findings are generated by the existing deterministic extraction and diagnostic engines. The sample does not inject arbitrary findings. Extraction is explicitly confirmed/approved and finding review explicitly accepts the resulting deterministic findings before downstream surfaces are available.
