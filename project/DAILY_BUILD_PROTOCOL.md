# Daily Build Protocol

Advance Sugar Platform Diagnostic by one coherent, testable vertical feature increment per run.

Review status, select the highest-priority dependency-complete item, implement one coherent slice, validate it, update documentation, package the repository, and publish changes on a dedicated agent branch with a draft pull request. Do not merge automatically or deploy production.

Priority path: create assessment -> upload -> validate -> extract -> review -> diagnose -> inspect evidence -> map -> report.
